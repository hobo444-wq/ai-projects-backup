# AI Projects Backup

AI Projects Backup is a personal backup utility maintained by hobo444-wq.

It is designed to back up the owner's selected Google Drive folder to a private Linux server using Rclone and Restic. It requests read-only access to Google Drive to list and download files and export Google Workspace documents.

The utility is for the owner's personal use. This website hosts information about the utility; it does not host backup files or account credentials.

[Privacy policy](privacy.html)

For questions, contact the maintainer through the support email shown on the application's Google consent screen.
