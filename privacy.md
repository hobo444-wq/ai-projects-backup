# Privacy Policy — AI Projects Backup

AI Projects Backup is a personal backup utility maintained by hobo444-wq for the owner's own Google Drive account.

## Google Drive access

The utility requests read-only access to list and download Google Drive files and export Google Workspace documents. This permission covers the account's Drive files; the backup configuration selects the AI Projects folder and its subfolders.

The utility does not modify or delete the original files in Google Drive.

## Use and storage

File contents and metadata are used to create backups on the owner's private Linux server. Backup files and Google authorization credentials are not published on this website.

The utility does not sell Google user data, use it for advertising, or use it to train AI models. It does not intentionally share backup contents with other parties.

## Retention and removal

Backups may retain earlier versions, including files later deleted from Google Drive, until the owner removes those backup snapshots.

The owner can revoke the utility's access through their Google Account's third-party connections settings. Revoking access stops future access but does not erase existing backups. Existing backups can be deleted separately from the server.

## Website hosting

This informational website is hosted by GitHub Pages. GitHub may collect technical information about website visits under its own privacy statement.
